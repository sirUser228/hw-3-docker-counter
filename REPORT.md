# Отчёт по домашнему заданию Docker

## Реализовано

- Создан Dockerfile.
- Приложение запускается от пользователя UID 10001.
- Настроены сервисы app и redis.
- Корневая файловая система приложения доступна только для чтения.
- Ограничения приложения: 256 MiB RAM и 1 CPU.
- Для Redis включено AOF-сохранение в именованный том.
- Настроены healthcheck обоих сервисов.
- Создан скрипт автоматической проверки scripts/check.sh.

## Результаты

Скрипт ./scripts/check.sh успешно выполнен два раза подряд. В обоих запусках получен результат All checks passed!

Проверены начальное значение счётчика, увеличение счётчика, сохранение данных после пересоздания приложения, поведение при остановке Redis, восстановление Redis и создание резервной копии.

Созданы две резервные копии Redis. Архивы находятся в каталоге backups и исключены из Git.
