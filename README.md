# Docker Counter

## Запуск

Скопировать настройки: `cp .env.example .env`

Запустить: `docker compose up -d --build`

Остановить: `docker compose down`

Приложение доступно по адресу http://localhost:8080.

## API

- `GET /` — получить значение счётчика.
- `POST /increment` — увеличить счётчик.
- `GET /healthz` — проверить HTTP-сервер.
- `GET /readyz` — проверить готовность приложения.

## Архитектура

- Сервисы app и redis запускаются через Docker Compose.
- Счётчик хранится в Redis.
- Данные Redis сохраняются в именованном томе с AOF.
- Наружу опубликован только порт приложения.
- Настроены healthcheck обоих сервисов.
- Приложение работает от UID 10001.
- Корневая файловая система приложения доступна только для чтения.
- Ограничения: 256 MiB RAM и 1 CPU.

## Проверка

Запустить `./scripts/check.sh`.
